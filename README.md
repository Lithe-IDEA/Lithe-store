## ⬇️ 在 Lithe 中安装

本仓库收录的插件按插件契约 v0 编写，需要新版 Lithe 桌面端（`desktop-v*` 预发布版本）。
旧版 macOS Lithe（0.x）读不了这份索引，插件市场会显示无法读取 Lithe Store。

桌面端已预置本仓库作为插件源：打开 **设置 → 插件 → 插件市场**，在“来源”中选择 Lithe Store
即可浏览和安装；安装前会弹窗列出插件权限、要运行的程序和来源仓库。

## 🤝 参与贡献

想写插件，先看 Rust Core 仓库的 [`shared/plugins/`](https://github.com/Lithe-IDEA/Lithe-core-rust/tree/main/shared/plugins)。想收录自己的插件、发布新版本或报告有问题的插件，请看 [CONTRIBUTING.md](CONTRIBUTING.md)。
上方的插件总览由 `scripts/render-readme.mjs` 根据 [`lithe-plugin-index.json`](lithe-plugin-index.json) 生成，索引合并到 main 后由 CI 自动同步。
